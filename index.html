# pose maps camera → CT, so CT points need its inverse,
# as in DRR.perspective_projection
mtre = (pred_pose.inverse()(f) - true_pose.inverse()(f)).norm(dim=-1).mean(dim=-1)
  1. pose maps camera points to CT points. That is why perspective_projection uses pose.inverse() for CT points.
  2. pose(f) treats the CT fiducials as camera points. So xvr's mTRE compares the purple points, which sit near the X-ray source.
  3. Both sets of points move with the same error. A shift moves both by the same amount. A rotation moves each point in proportion to its distance from the rotation centre: about – mm for the fiducials, but about – mm for the purple points.
